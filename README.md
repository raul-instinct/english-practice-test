# English practice (AMIRNET style)

Choose basic, intermediate or advanced. Each level has its own 26 original questions: 10 Sentence Completion, 8 Restatement and 8 Reading Comprehension (two passages). 78 questions total.

Hebrew instructions, English content, answer explanations, section scores and practice tips based on mistakes. Answers shuffle on each attempt; a retake uses the same questions. Results are not saved or sent to a server.

A free independent practice tool, not an official, adaptive or calibrated exam. The A2-B1 / B1-B2 / B2-C1 hints are broad practice estimates only. Percentage scores are not official AMIRNET scores and are not equivalent across levels.
